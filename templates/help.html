Справка по корпусному менеджеру

Предметная область: Животные (русский язык)

📖 Основные понятия
Лемма

Начальная (словарная) форма слова.

Для существительных — именительный падеж, единственное число. Для глаголов — инфинитив.

Пример: Для слов "медведь", "медведя", "медведю" лемма — "медведь".
Для слов "ходит", "ходил", "ходила" лемма — "ходить".

Словоформа

Конкретная грамматическая форма слова.

Слово в том виде, в котором оно встречается в тексте, с определённым окончанием.

Пример: "медведя", "медведю", "медведи" — это разные словоформы одной леммы "медведь".

Конкорданс

Слово в контексте.

Показывает, как слово употребляется в окружении других слов. Обычно выводится несколько слов слева и справа от искомого слова.

Пример: Для слова "медведь":
"В России бурый" медведь "широко распространён"
"Охота на" медведя "строго регулируется"

Часть речи (POS)

Грамматическая категория слова.

Определяет роль слова в предложении.

Основные части речи: существительное, прилагательное, глагол, наречие, местоимение, предлог и т.д.

Морфологические признаки

Грамматические характеристики слова.

  • Род: мужской, женский, средний
  • Число: единственное, множественное
  • Падеж: именительный, родительный, дательный, винительный, творительный, предложный
  • Время (для глаголов): настоящее, прошедшее, будущее

Пример: Слово "медведя" — существительное, мужской род, единственное число, родительный падеж.

Корпус текстов — это структурированная коллекция текстов, размеченная по различным лингвистическим параметрам.

В данном корпусе представлены тексты на русском языке, относящиеся к предметной области "Животные". Корпус включает:

  • Научно-популярные статьи о животных
  • Энциклопедические статьи
  • Художественные тексты с описанием животных
  • Учебные материалы

Разметка корпуса:

  • Метаданные документов (автор, год, жанр, источник)
  • Предложения с порядковыми номерами
  • Токены (слова) с морфологической информацией
  • Синтаксическая разметка (связи между словами)
  • Конкорданс (слово в контексте)

1. Поиск по словоформе

Ищет точное совпадение с введённым словом. Учитывает регистр и окончания.

Пример: "медведь" — найдёт только слово "медведь"

2. Поиск по лемме

Ищет все формы слова (нормальная форма + все окончания).

Пример: "медведь" — найдёт "медведь", "медведя", "медведю", "медведи" и т.д.

3. Конкорданс

Показывает слово в контексте (слева и справа от слова). Позволяет увидеть употребление слова в окружении.

4. Морфологический поиск

Поиск по грамматическим категориям. Формат запроса: параметр=значение&параметр=значение

Пример: pos=существительное&number=множественное&case=родительный

Доступные параметры:

  • pos — часть речи (существительное, прилагательное, глагол...)
  • gender — род (мужской, женский, средний)
  • number — число (единственное, множественное)
  • case — падеж (именительный, родительный...)

🌳 Что такое синтаксический анализ?

Синтаксический анализ (парсинг) определяет грамматическую структуру предложения и связи между словами.

Дерево зависимостей

Визуализирует иерархическую структуру предложения, где:

  • Узлы — слова предложения
  • Связи — грамматические отношения между словами
  • Корень — главное слово (обычно сказуемое)

Пример: В предложении "Бурый медведь ест малину" связи будут:

  • медведь → ест (подлежащее)
  • Бурый → медведь (определение)
  • ест → малину (дополнение)
Типы синтаксических отношений
  • nsubj — подлежащее
  • obj — дополнение
  • amod — согласованное определение
  • nmod — именное определение
  • advmod — обстоятельство
  • ROOT — корень предложения
Синтаксические группы
  • NP (именная группа) — существительное с зависимыми словами (например, "бурый медведь")
  • VP (глагольная группа) — глагол с зависимыми словами (например, "ест спелую малину")
  • PP (предложная группа) — предлог с существительным (например, "в лесу")
Члены предложения
  • Подлежащее — кто? что? (медведь)
  • Сказуемое — что делает? (ест)
  • Дополнение — кого? что? (малину)
  • Определение — какой? (бурый, спелую)
  • Обстоятельство — где? когда? (в лесу)
Как пользоваться
  1. Откройте любой документ в корпусе
  2. Нажмите кнопку "Синтаксический разбор"
  3. Выберите "Выполнить анализ всех предложений"
  4. Изучайте дерево зависимостей, таблицу токенов и синтаксические группы
Совет: Наведите курсор на слово в графе или таблице, чтобы подсветить соответствующий узел. Цвет узла показывает его роль в предложении.

Статистический модуль предоставляет:

  • Общая статистика — количество документов, предложений, слов
  • Частотные слова — самые употребляемые слова в корпусе
  • Распределение частей речи — процентное соотношение
  • Морфологическая статистика — распределение по роду, числу, падежу
  • Синтаксическая статистика — типы связей, их частотность

Доступен экспорт статистики в форматах JSON и CSV.

Для добавления нового документа в корпус:

  1. Перейдите в раздел "Загрузить"
  2. Заполните метаданные (название, автор, год, жанр, источник)
  3. Выберите файл (поддерживаются форматы TXT, RTF, PDF, DOCX, DOC)
  4. Нажмите "Загрузить"

После загрузки документ автоматически обрабатывается:

  • Разбивается на предложения
  • Токенизируется (разбивается на слова)
  • Выполняется морфологический анализ
  • Выполняется синтаксический анализ
  • Строится конкорданс

Q: Какие форматы файлов поддерживаются?

A: Поддерживаются TXT, RTF, PDF, DOCX, DOC файлы.

Q: Какой объём текста можно загрузить?

A: Максимальный размер файла — 16 МБ.

Q: Как интерпретировать результаты конкорданса?

A: В конкордансе показывается ключевое слово, выделенное жирным, и контекст (до 5 слов слева и справа).

Q: Что означают цвета в дереве зависимостей?

A: Красный — подлежащее, зеленый — сказуемое, синий — дополнение, желтый — определение, голубой — обстоятельство.

Q: Можно ли скачать результаты синтаксического анализа?

A: Да, на странице разбора предложения доступен экспорт в JSON и CONLL-U форматы.

Q: Чем отличается поиск по словоформе от поиска по лемме?

A: Поиск по словоформе находит только точное совпадение (например, "медведя"). Поиск по лемме находит все формы слова (медведь, медведя, медведю, медведи...).

Q: Что такое CONLL-U формат?

A: Это стандартный формат для представления синтаксически размеченных текстов, используемый в международных проектах по обработке естественного языка.
