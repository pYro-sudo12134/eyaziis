О корпусе

Корпус текстов по теме "Животные" включает:

  • Научно-популярные статьи о животных
  • Энциклопедические описания видов
  • Художественные тексты с описанием животных
  • Учебные материалы по зоологии

Корпус размечен на уровнях:

  • Документы (метаданные)
  • Предложения
  • Токены (слова и пунктуация)
  • Морфологическая разметка
Возможности
  • Конкорданс - вывод слова в контексте
  • Поиск по словоформам - точное совпадение
  • Поиск по леммам - все формы слова
  • Морфологический поиск - по частям речи, роду, числу, падежу
  • Статистика - частотные слова, распределение по категориям
  • Экспорт - выгрузка результатов в JSON/CSV
