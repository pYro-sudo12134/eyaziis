# Автоматизированная система формирования словаря

## Описание проекта

Этот проект представляет собой автоматизированную систему для формирования и управления словарём русского языка. Система позволяет обрабатывать текстовые файлы, извлекать словоформы, выполнять морфологический анализ и сохранять результаты в базу данных PostgreSQL.

## Основные возможности

- **Загрузка текстовых файлов** (TXT, RTF) для анализа
- **Автоматическое извлечение словоформ** с подсчётом частоты встречаемости
- **Морфологический анализ** с использованием библиотеки pymorphy3
- **Управление предложениями** по морфологическому разбору
- **Ручное редактирование** морфологической информации
- **Поиск по словарю** с фильтрацией
- **Экспорт данных** в JSON формат
- **Интуитивный графический интерфейс** на базе tkinter

### Структура модулей:
- `database.py` - работа с базой данных PostgreSQL
- `text_processor.py` - обработка текстовых файлов
- `morphology_analyzer.py` - морфологический анализ слов
- `suggestion_manager.py` - управление предложениями по морфологии
- `corpus_manager.py` - управления корпусами
- `corpus_init.py` - запуск корпусования
- `app.py` - точка входа в приложение

## Требования

### Системные требования
- Python 3.8+
- PostgreSQL 15+
- Docker (для упрощённого развёртывания БД)

### Зависимости Python
См. файл `requirements.txt`:
```
psycopg2-binary>=2.9.5
nltk>=3.8
striprtf>=0.0.24
pymorphy3>=1.2.0
```

## Установка и запуск

### 1. Настройка базы данных

#### Вариант A: Использование Docker (рекомендуется)
```bash
chmod +x postgres-init.sh
./postgres-init.sh
```

#### Вариант B: Ручная установка PostgreSQL
1. Установите PostgreSQL 15+
2. Создайте базу данных:
```sql
CREATE DATABASE postgres;
CREATE USER postgres WITH PASSWORD 'postgres';
GRANT ALL PRIVILEGES ON DATABASE postgres TO postgres;
```

### 2. Установка Python зависимостей
```bash
pip install -r requirements.txt
python -m nltk.downloader punkt punkt_tab
```

### 3. Запуск приложения
```bash
python main.py
```

## Использование

### Основные функции GUI:

1. **Загрузка файлов**:
   - Нажмите "Загрузить файл" для обычной загрузки
   - "Загрузить с авторазбором" для автоматического морфологического анализа

2. **Просмотр словаря**:
   - Все словоформы отображаются в таблице слева
   - Сортировка по алфавиту и частоте встречаемости

3. **Морфологический анализ**:
   - Выберите слово из таблицы
   - Нажмите "Авторазбор" для автоматического анализа
   - Отредактируйте поля вручную и нажмите "Сохранить"

4. **Управление предложениями**:
   - Нажмите "Показать предложения"
   - Просмотрите автоматические разборы
   - Примите или отклоните предложения

5. **Поиск**:
   - Введите слово в поле поиска
   - Результаты обновляются автоматически

6. **Экспорт**:
   - Нажмите "Экспорт в JSON"
   - Сохраните полный словарь в JSON формате

## Структура базы данных

### Таблицы:

1. **word_forms** - хранит словоформы:
   - `id` - уникальный идентификатор
   - `word_form` - словоформа (уникальная)
   - `frequency` - частота встречаемости
   - `created_at` - дата создания

2. **morphology** - морфологическая информация:
   - `id` - уникальный идентификатор
   - `word_form_id` - ссылка на словоформу
   - `part_of_speech` - часть речи
   - `gender` - род
   - `number` - число
   - `case_form` - падеж
   - `custom_note` - произвольная заметка

## Пример работы

### Обработка текстового файла:
1. Нажмите "Загрузить файл" и выберите текстовый файл
2. Система автоматически извлечёт все словоформы
3. При использовании "Загрузить с авторазбором" будет выполнен морфологический анализ
4. Результаты сохранятся в базу данных

### Морфологический анализ слова:
1. Выберите слово в таблице
2. Нажмите "Авторазбор" для получения анализа
3. Система предложит часть речи, род, число и падеж
4. При необходимости отредактируйте и сохраните
